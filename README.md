# נקדן לקריינים — Nikud for Narrators

ניקוד פונטי / מעשי להקראה ושידור. **עצמאי לחלוטין** — רץ מקומית על המחשב, ללא Dicta וללא אינטרנט.

## הפעלה
השירות עולה לבד בהתחברות (LaunchAgent `com.pele.nakdan-karyanim`) → http://localhost:8788

```bash
launchctl kickstart -k "gui/$(id -u)/com.pele.nakdan-karyanim"   # הפעלה מחדש אחרי שינוי קוד
tail -f ~/Library/Logs/pele-nakdan-karyanim.log                   # לוג
./start.sh                                                        # הפעלה ידנית (אם השירות כבוי)
```
חשוב: לפתוח תמיד דרך `http://localhost:8788` — לא כקובץ (`file://`).

## מה זה עושה
- קלט: **PDF** (כולל קבצי דפוס) / **TXT** / הדבקה. הכול נטען כמסמך אחד בגלילה רציפה — בלי כפתורי "עמוד הבא".
- **PDF מוצג אחד-לאחד**: כל שורה באותו מקום, אותו רוחב, אותו גודל ואותם שוליים כמו במקור (בלי כותרת רצה,
  מספר עמוד וסימוני הערות). הניקוד מתווסף מעל אותה פריסה. כל עמוד מנוקד כשמתקרבים אליו.
- **זום = זום לכל הדף** (צביטה / Ctrl+גלגלת / ‎+ ‎− / "התאם"), כמו בקורא PDF. הטקסט לא "נשפך" מחדש.
- שלושה טאבים: **טקסט מקורי** · **ניקוד דקדוקי (תקני)** · **ניקוד לקריינים (פונטי)**.
- **הניקוד לעולם לא משנה את אותיות המילה — רק מוסיף סימנים.**
- צפיפות: **מינימלי** = מילים קריטיות + תחיליות · **בינוני** = + דגש ב-בכ״פ ונקודת שׁ/שׂ · **מלא** = כל המילים.
- **תחילית ב/כ/ל מנוקדת תמיד** (בֶּ/בַּ, לֶ/לַ) — כי היא משנה משמעות.
- **מקרא**: מסגרת סגולה = מילה קריטית (מלעיל / קמץ קטן / שווא נע; ריחוף מסביר למה) · ▲ = ההברה המוטעמת.
- לחיצה על מילה: בחירת הגיית התחילית (לֶ = for, לַ = to the, לִ), **עורך אות-אות** (בוחרים אות ואז תנועה /
  דגש / הטעמה), הקלדה חופשית, "חזרה לאוטומטי", "🔖 הפסקתי כאן". תיקונים נשמרים לפי מסמך+עמוד; יש בטל/בצע-שוב.

## הנחיות לקריין
סימון מילה או כמה מילים עם הנחיה: גוררים עם העכבר על המילים (או לוחצים על מילה ← "🎙 הנחיה לקריין").
הנחיות מוכנות: הדגשה · להאט · להאיץ · הפסקה/נשימה אחרי · בשקט · בעוצמה · אינטונציה עולה · ירידה/סגירה ·
בחיוך · ציטוט/קול אחר — ולכל אחת אפשר להוסיף טקסט חופשי, או לבחור "הערה חופשית" ולכתוב רק משלך.
המילים מקבלות קו צבעוני, והתווית מופיעה בשוליים ליד השורה (גם במסך מלא). לחיצה על התווית = עריכה/מחיקה.
"🎙 הנחיות" בסרגל התחתון מציג/מסתיר. נשמר ב-`nk2-notes` לפי מסמך+עמוד.

## ניווט והתמצאות
- גלילה רציפה בין כל העמודים; מונה עמוד ופרק מתעדכנים תוך כדי.
- קפיצה למספר עמוד ולפרק (מתוכן העניינים של הספר, או מסימניות ה-PDF).
- **🔖 הפסקתי כאן** — עמוד + המילה המדויקת (מהחלונית של מילה, לחיצה כפולה במסך מלא, `B`, או הכפתור —
  שמסמן את המילה שבקו הקריאה). בפתיחה הבאה של אותו קובץ ממשיכים משם.

## מסך מלא (קריאה / טלפרומפטר)
אותם עמודים, נקי מתפריטים, ממורכז. פקד צף: ▶ גלילה אוטומטית רציפה, מהירות, זום, 🔖, מונה עמודים.
קיצורים: רווח = הפעל/עצור · ↑ ↓ / PageUp/Down גלילה · ← → עמוד · `B` סימנייה · `+` `−` `0` זום · Esc יציאה.

## הארכיטקטורה
```
PDF ─► pdf_extract.py ─► עמודים בסדר קריאה אמיתי (BiDi), פסקאות, פרקים, מספרי עמוד
טקסט ─► nikud_engine_local.py ─► phonikud (מודל מקומי, onnxruntime):
            אותיות נשמרות · קמץ קטן U+05C7 · שווא נע U+05BD · הטעמה U+05AB
        ─► שכבת הקריין שלנו: שווא נח מושמט · שווא נע→סגול · קמץ קטן→חולם ·
            איחוד E/O/U · דגש רק ב-בכ"פ · הטעמה — לפי המתגים
```
- `server.py` — שרת stdlib: `/`, `/api/pdf_pages`, `/api/nikud_lines`, `/api/nikud`, `/api/extract_pdf`, `/health`.
- `nikud_engine_local.py` — המנוע. יישור הפלט מעוגן-אותיות: מפרידים (רווחים, פיסוק, מקף ־, אנגלית, מספרים)
  נלקחים תמיד מהמקור; מהמודל רק אותיות+סימנים (המודל מוחק מקפים!). `process_lines` מנקד עמוד כטקסט רציף
  ומחזיר אסימונים לפי שורה: `{o: אותיות, v: ניקוד גולמי כולל הטעמה/שווא-נע/קמץ-קטן, p: מספר אותיות תחילית}`.
- `nikud_core.js` — כל הגזירה לתצוגה בצד הדפדפן (דקדוקי / קריינים / חלקי, חלופות תחילית, עריכת אות).
  זהה ל-`transpile` שבפייתון (נבדק מילה-מילה). לכן מתגי הכללים מיידיים ואינם דורשים ניקוד מחדש.
- `pdf_extract.py` — rawdict לכל תו → הצמדת סימני ניקוד לאות → קיבוץ לשורות → אלגוריתם BiDi של יוניקוד
  (`python-bidi`; סוגריים מוחלפים זמנית בתווים ניטרליים כדי שלא יתהפכו) → פסקאות → הסרת כותרת רצה, מספר
  עמוד, שורות-דפוס וסימוני הערות → גיאומטריה לכל שורה (x0,x1,y,גודל) + פרקים מתוכן העניינים.
- `app.js` + `index.html` — הממשק: `View` אחד לעורך ואחד למסך מלא; עמודים נטענים ומנוקדים בעצלתיים.
  התאמת רוחב שורה: מרווח-מילים ב-em (ובמקרה קיצון scaleX), כך שכל שורה ברוחב המדויק שלה ב-PDF.
- `nikud_engine.py` — מנוע חלופי מבוסס Dicta (אונליין): `NIKUD_ENGINE=dicta`.
- `models/phonikud-1.0.int8.onnx` — המודל (~294MB). `.venv/` — פייתון 3.13.

תלויות (ב-.venv): `phonikud`, `phonikud-onnx`, `onnxruntime`, `pymupdf`, `python-bidi`.

## נשמר בדפדפן
IndexedDB `nikud-karyanim`: המסמך הטעון + ניקוד העמודים שכבר חושבו. localStorage: `nk2-state` (הגדרות ומיקום),
`nk2-edits` (תיקוני מילים), `nk2-progress` (היכן הפסקת). הנתונים הם לפי דפדפן.

## מגבלות ידועות
- הטעמה והומוגרפים: המודל מדויק ברוב המקרים, לא ב-100% — לכן יש עריכה ידנית לכל מילה.
- PDF סרוק (תמונה בלי שכבת טקסט) לא נתמך — נדרש OCR.
- PDF בשני טורים: שורות מקובצות לפי גובה בתוך בלוק; פריסות מורכבות עלולות להתערבב.
